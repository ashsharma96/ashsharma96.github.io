2023 to now

Most days, my job is

Getting AI agents to talk to each other,

without starting a fight.

A fight is my word for agents disrupting each other.

At Ingenia AI I build multi-agent systems where each agent does one job well, and we reuse what we build so nothing gets built twice.

An orchestrator, not a group chat.

A planner decides which agent acts next and which tools it may use. The hard rules live in code, not in the prompt, so no agent can talk its way past them.

Every query passes three gates.

  1. Does it carry sensitive data?
  2. Can that data be masked?
  3. How hard is the question?

Self-hosted when the data can't leave the building. An API when it can. Decided on privacy and security, not on hype.

2018 to 2020

It started with 50,000 cries.

For my M.Tech, I recorded infant cries myself at a children's NICU in Udhampur, with consent, five seconds at a time.

Collecting and labelling took most of the time. That part never shows up in a model card.

Five kinds of cry: hunger, pain, sleepiness, discomfort and medical distress.

Then the model: an LSTM on MFCC, pitch and energy features. Around 90% test accuracy. It was the easy part.
